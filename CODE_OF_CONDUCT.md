# Code of conduct

Bellboard follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and kind, disagree about ideas rather than people, and assume good intent.
Harassment, insults and personal attacks aren't tolerated, in issues, pull requests, discussions or
anywhere else the project lives.

If someone's behaviour worries you, report it privately through the repository's
[security advisory form](https://github.com/omer-yld/bellboard/security/advisories/new) (it reaches only
the maintainers) or by contacting the maintainer through their GitHub profile. Reports are handled
confidentially.
